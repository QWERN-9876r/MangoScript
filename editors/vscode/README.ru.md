# MangoScript для VS Code

[English](README.md) · **Русский**

Поддержка MangoScript — языка с семантикой JavaScript, синтаксисом в духе Go и статической
типизацией — для файлов `.mango`: подсветка, ошибки прямо при наборе и автодополнение.

## Ошибки и автодополнение

Расширение запускает языковой сервер с компилятором MangoScript. Пока вы печатаете, он подчёркивает
ошибки и предупреждения, которые напечатал бы `mango build`, и дополняет:

- имена в области видимости: переменные, параметры, функции, классы, компоненты, глобальные имена
  вроде `document` и ключевые слова;
- члены после `.` и `?.` с их типами: у классов (приватные — только внутри класса), интерфейсов,
  объектов, строк, массивов и DOM;
- типы там, где пишется тип: `let user Us|`;
- теги и компоненты в разметке, `<Ca|`, а также свойства компонента или атрибуты и события
  элемента, `<input on|`.

Типы стандартной библиотеки и DOM берутся из lib-файлов TypeScript, которые расширение везёт с собой.
Импорты других файлов `.mango` и пакетов с типами проверяются так же, как в `mango build`.
Разметка и компоненты — ошибки, если ближайший `package.json` не включает их через
`"mangoscript": { "markup": true }`, как и для `mango build`.

## Подсветка

Подсвечиваются:

- ключевые слова, объявления `func`, `comp`, `class`, `interface`, `type`, `state` и `mount()`;
- типы в стиле Go: `number`, `[]Todo`, `?User`, имена классов и интерфейсов;
- строки, шаблонные строки с `${...}`, числа, комментарии;
- разметка: теги, компоненты, атрибуты, `on*`, `bind:value`, выражения в `{...}`, а также `if`,
  `for` и `switch` внутри неё.

Ещё расширение настраивает комментарии (`Cmd+/`), закрытие скобок и кавычек и отступ в 4 пробела.

## Установка

Из корня репозитория:

```sh
npm run vscode:install
```

Команда собирает клиент и языковой сервер вместе с компилятором в `editors/vscode/dist`
(`npm run vscode:build`), упаковывает `editors/vscode/mangoscript.vsix` и устанавливает его через
`code`. После изменений в грамматике или компиляторе её нужно запустить снова и перезагрузить окно
VS Code.

Для разработки расширения удобнее окно, в котором оно загружено прямо из этой папки; сначала его
нужно собрать:

```sh
npm run vscode:build
code --extensionDevelopmentPath="$PWD/editors/vscode"
```

Исходники расширения лежат в `src/`: `extension.mts` запускает сервер, `server.mts` отвечает VS
Code, а само автодополнение — в компиляторе (`src/completion.ts` и последний слой проверки типов,
`src/checker/completion.ts`). Их проверяют `tests/completion.test.ts` и
`tests/vscode-server.test.ts`.

Грамматика проверяется тестами в `tests/vscode-grammar.test.ts` тем же движком, что использует VS
Code (`vscode-textmate`). Посмотреть области под курсором можно командой «Developer: Inspect Editor
Tokens and Scopes».

## Ограничения

Как и в `mango build`, в файле с синтаксической ошибкой видны только синтаксические ошибки: типы
проверяются, когда файл разбирается. Импортируемые файлы `.mango` видны такими, какими они сохранены
на диске.

Подсветка — это грамматика TextMate: она смотрит на текст строки, а не на синтаксическое дерево.
Поэтому:

- `<` считается началом разметки, если перед ним нет значения (имени, `)` или `]`) и сразу после
  него идёт имя тега. `a < b` и `i<n` — сравнения, а `return <div>` — разметка;
- типы узнаются по виду: встроенные (`number`, `string`…) и имена с заглавной буквы. Свои типы со
  строчной буквы (`type id = number`) подсвечиваются как обычные имена.
