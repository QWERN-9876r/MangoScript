# MangoScript для VS Code

Подсветка синтаксиса MangoScript — языка с семантикой JavaScript, синтаксисом в духе Go и
статической типизацией — для файлов `.mango`.

Подсвечиваются:

- ключевые слова, объявления `func`, `comp`, `class`, `interface`, `type` и `state`;
- типы в стиле Go: `number`, `[]Todo`, `?User`, имена классов и интерфейсов;
- строки, шаблонные строки с `${...}`, числа, комментарии;
- разметка: теги, компоненты, атрибуты, `on*`, `bind:value`, выражения в `{...}`, а также `if`,
  `for` и `switch` внутри неё.

Ещё расширение настраивает комментарии (`Cmd+/`), закрытие скобок и кавычек и отступ в 4 пробела.

## Установка

Из корня репозитория:

```sh
npm run vscode:install
```

Команда собирает `editors/vscode/mangoscript.vsix` и устанавливает его через `code`. После
изменений в грамматике её нужно запустить снова и перезагрузить окно VS Code.

Для разработки грамматики удобнее окно, в котором расширение загружено прямо из этой папки:

```sh
code --extensionDevelopmentPath="$PWD/editors/vscode"
```

Грамматика проверяется тестами в `tests/vscode-grammar.test.ts` тем же движком, что использует VS
Code (`vscode-textmate`). Посмотреть области под курсором можно командой «Developer: Inspect Editor
Tokens and Scopes».

## Ограничения

Это грамматика TextMate: она смотрит на текст строки, а не на синтаксическое дерево. Поэтому:

- `<` считается началом разметки, если перед ним нет значения (имени, `)` или `]`) и сразу после
  него идёт имя тега. `a < b` и `i<n` — сравнения, а `return <div>` — разметка;
- типы узнаются по виду: встроенные (`number`, `string`…) и имена с заглавной буквы. Свои типы со
  строчной буквы (`type id = number`) подсвечиваются как обычные имена.
